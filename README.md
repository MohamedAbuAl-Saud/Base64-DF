# Base64 Encoder/Decoder Tool

A Base64 encoding and decoding tool via the command line (Bash). This tool provides an interactive interface for users to encode and decode text, along with the option to view developer information.

## Features:
- Encode text to Base64.
- Decode Base64 encoded text.
- Display developer information.
- Interactive and visually appealing interface with color support.
